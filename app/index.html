Help

A step looks stuck

Each slow step shows a clock. On an older computer, installing Docker and unpacking the box can take a few minutes each. If nothing moves for ten minutes, quit IMD Agents and open it again: setup picks up where it left off.

The password box

Once, a box from IMD Agents asks for your Mac's password, so Docker's installer can finish. The password goes to macOS, never to IMD.

Windows asks to make changes

Only if WSL, which Docker runs on, isn't installed yet: Windows asks to let Windows Subsystem for Linux make changes. Choose Yes. Docker itself installs for you alone, with no prompt.

A restart

A PC that never had WSL restarts once, after Docker installs. Setup says so before it starts. Save your work and choose Restart your PC: setup opens again after it and starts Docker.

Virtualization is off

Docker needs your PC's virtualization. Turn it on in its BIOS or UEFI settings, often called Intel VT-x or AMD SVM, then try again.

Docker's questions

Skip its sign-in: your agent doesn't need a Docker account. If your Mac asks to let Docker find devices on your network, choose Don't Allow. The box only needs the internet.

Signing in to Claude

Your browser opens Claude's sign-in. Sign in, copy the code Claude shows at the end, and paste it into setup under Code from Claude.

Stopping or removing it

Turn your agent off from the menu bar or taskbar. To remove the box and free your seat, follow Remove it in the box's guide.
